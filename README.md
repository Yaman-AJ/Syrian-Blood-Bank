## 🎯 الوظائف الرئيسية للموقع

### 1. **إدارة المستخدمين والتسجيل**
- ✅ تسجيل دخول وإنشاء حسابات
- ✅ إدارة حالة تسجيل الدخول عبر localStorage
- ✅ ملفات شخصية للمستخدمين
- ✅ تسجيل الخروج الآمن

### 2. **البحث عن فصائل الدم** (`Bloodtype.html`)
- 🔍 بحث متقدم بفلاتر متعددة:
  - نوع فصيلة الدم (A, B, AB, O)
  - عامل Rh (موجب/سالب)
  - المحافظة
- 📊 عرض نتائج تفصيلية للمراكز المتاحة
- 🗺️ دليل كامل للمراكز مع معلومات الاتصال

### 3. **خريطة المراكز** (`Map.html`)
- 🗺️ خريطة تفاعلية لمواقع مراكز التبرع
- 🏷️ مرشحات حسب المحافظات
- 📍 علامات توضيحية على الخريطة
- 📋 قائمة تفصيلية بالمراكز مع حالة التوفر

### 4. **حجز المواعيد** (`Date.html`)
- 📅 نظام حجز مواعيد متكامل
- 🏥 اختيار المحافظة والمركز
- 📝 إضافة ملاحظات شخصية
- 🔗 رابط سريع لطلب الإعفاء

### 5. **نظام الإعفاء** (`exemption.html`)
- 📄 نموذج إلكتروني لطلب الإعفاء
- 📎 رفع الوثائق الداعمة
- 👤 متابعة حالة الطلب
- 📧 تأكيد إلكتروني للطلب

### 6. **لوحة تحكم المدير** (`Admin Dashboard.html`)
- 📊 إحصائيات شاملة عن التبرعات
- 📈 مخططات بيانية لتطور التبرعات
- 🚨 نظام تنبيهات للفصائل النادرة
- 👥 إدارة المتبرعين والمراكز

### 7. **التواصل والدعم** (`Contactus.html`)
- 📞 قنوات اتصال متعددة
- 📧 نموذج تواصل مباشر
- 🔗 روابط وسائل التواصل الاجتماعي
- 📱 دعم على مدار الساعة

## 📊 قاعدة البيانات (الوهمية)

### **مراكز التبرع:**
- 15 مركزاً افتراضياً في مختلف المحافظات
- معلومات كاملة لكل مركز:
  - الاسم والعنوان
  - أنواع فصائل الدم المتاحة
  - عدد الأكياس المتوفرة
  - حالة المركز (متوفر/محدود/غير متوفر)

### **فصائل الدم:**
- جميع فصائل الدم الرئيسية (A, B, AB, O)
- كلا نوعي Rh (موجب وسالب)
- تحديث ديناميكي للكميات المتوفرة

### **للمتبرع الجديد:**
1. إنشاء حساب ← تسجيل الدخول ← البحث عن مركز ← حجز موعد ← التبرع

### **لطلب الإعفاء:**
